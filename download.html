安装步骤

五步完成，两分钟搞定

1
安装 Java 8 JDK

必须安装 Java 8（1.8）。项目 Gradle toolchain 已锁定该版本，更高或更低的 JDK 都无法编译与运行。

2
安装 Minecraft 1.8.9 与 Forge

StarShack 是 Forge 模组，需要先安装 Minecraft 1.8.9 及对应版本的 Forge 加载器。

3
获取 Starshack.jar

从上方 Releases 页面下载预编译 jar，或自行构建产出 build/libs/Starshack.jar。

4
放入 mods 文件夹

将 jar 文件复制到 .minecraft/mods/ 目录。Windows 下通常位于 %appdata%\.minecraft\mods\。

5
启动游戏并打开 ClickGUI

启动 Forge 1.8.9，默认按 Right Shift (RSHIFT) 打开 ClickGUI，即可管理全部模块。按键可在 Settings 模块中修改。

StarShack 是面向私有服务器、单人游戏与学习 / 模组研究用途的实用模组。在公开服务器（尤其是竞技类服务器）上使用风险自负，可能违反其服务条款。作者不对任何封禁或后果负责。
