隐私政策

StarShack 不收集、不上传、不出售你的任何数据。以下是完整说明，包括全部会发起网络请求的场景。

最后更新：2026-09-27 · 适用版本 v1.1.4

我们收集什么

一句话：什么也不收集

遥测与分析 无使用统计 · 无崩溃上报
从不

客户端不包含任何遥测、埋点或崩溃上报代码。我们无法知道你何时启动、用了哪些模块、玩了多久。

账号与身份信息 无注册 · 无登录 · 无账号体系
从不

StarShack 没有账号系统，不需要你登录，也不会读取或上传你的 Minecraft 正版账号凭据、会话令牌或密码。

配置与模块设置 仅保存在你自己的电脑上
本地

所有模块开关、按键绑定与参数改动都会在变更时自动写入本机配置文件，并在启动时读回。这些内容从不离开你的设备。

本网站 静态页面 · 无统计脚本 · 无 Cookie
静态

本站是纯静态页面，不设置 Cookie，不接入访问统计。唯一例外：页面字体由 Google Fonts 提供，加载时你的 IP 会被 Google 看到。

什么时候会联网

只有下面两种情况，且都由你主动触发

Hypixel 战绩查询 DuelsStats 模块
按需

启用该模块并填入自己的 Hypixel API Key 后，客户端会访问 api.mojang.com（玩家名转 UUID） 与 api.hypixel.net（读取战绩）。不使用该模块则完全不发起这些请求。

Hypixel API
脚本系统（会附带校验令牌） 加载第三方脚本时发送
按需

加载第三方脚本时，客户端会在请求头 id 中附带一个由当前时间窗口派生的滚动令牌 （约每 20 秒变化一次）。经源码核对，该值不包含机器名、CPU 型号、核心数等硬件信息， 也无法用于跨会话追踪 —— 源码中读取硬件信息的那一步因实现缺陷未生效，实际发送的只是时间派生值。 不使用脚本功能则不会触发。请注意：你访问的任何第三方服务器都会看到你的 IP，这与使用哪种客户端无关。

已修复：该令牌已在源码中移除，自下一版本起，加载脚本不再附带任何标识。 当前发布版（v1.1.4 及更早）仍会发送上述时间派生值。

源码依据：ScriptManager · NetworkUtils.getTextFromURL · SystemUtils.getHardwareIdForLoad
脚本内部的网络行为 由你运行的脚本决定
自控

脚本 API 提供 HTTP 请求、WebSocket 与远程图片加载能力。这些请求由你选择运行的脚本发起，目标地址取决于脚本内容， 不属于客户端自身行为。运行来源不明的脚本等同于运行来源不明的程序，请自行判断。

关于本页的范围

本页只描述 StarShack 客户端与本站的行为，不涵盖你连接的第三方服务器、Hypixel 或任何脚本来源方的隐私做法。 客户端以 GPLv3 开源，上述每一条都可以在源码中核对。若发现本页描述与实际行为不符，请 提交 Issue，我们会更正。
