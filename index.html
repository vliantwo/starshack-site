核心特性

为 Minecraft 玩家打造的下一代实用模组体验

隐私优先

零遥测、零分析、零数据外传。所有操作完全在本地完成，你的数据只属于你自己。

配置持久

所有设置自动保存，重启后完美恢复。告别每次启动都要重新配置的烦恼。

无限扩展

完整的脚本 API + 清晰的模块架构，添加新模块从未如此简单。Setting 基类、多种设置类型开箱即用。
